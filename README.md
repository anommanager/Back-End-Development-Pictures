# Back-End-Development-Pictures

## Project Title
Back-End Development Pictures Microservice

## Environment Setup

This project was created from the IBM Skills Network template.

### Prerequisites
- Python 3.9.x
- Virtual environment: `backend-pics-venv`

### Setup Instructions

1. Clone the repository:
   ```
   git clone https://github.com/anommanager/Back-End-Development-Pictures.git
   cd Back-End-Development-Pictures
   ```

2. Run the setup script:
```
bin/setup.sh
```
This creates the `backend-pics-venv` virtual environment.

3. Activate the virtual environment:
```
source backend-pics-venv/bin/activate
```

4. Verify Python version:
```
python --version
```
Python 3.9.x

5. Run the application:
```
flask run
```
